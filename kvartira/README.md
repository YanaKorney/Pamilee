# Моя квартира

Программа, которая показывает, как будет выглядеть квартира после ремонта.

Вы загружаете дизайн-проект от дизайнера, программа разбирает его на комнаты,
строит трёхмерную модель и создаёт фотореалистичные картинки — с вашей реальной
планировкой, а не с придуманной.

```
Дизайн-проект  →  комнаты и размеры  →  3D-модель  →  картинки  →  прогулка по квартире
```

Всё работает **на вашем компьютере**. Ни регистрации, ни подписки, ни облака:
планы и фотографии никуда не уходят, кроме того момента, когда вы сами нажимаете
«Разобрать план» или «Создать визуализацию».

---

## Что уже готово

| Готово сейчас | Появится дальше |
|---|---|
| Запуск в два клика | Распознавание комнат, стен, окон, мебели |
| Создание проектов | Проверка и правка планировки |
| Параметры квартиры: площадь, высота потолка | Референсы и пожелания по комнатам |
| Загрузка PDF, JPG, PNG, WEBP | 3D-модель и просмотр |
| Просмотр всех листов проекта | Визуализации комнат |
| Страница «Настройки» | 3D-тур по квартире |

Программа отличает **векторный чертёж** от обычной картинки и честно
говорит об этом. Разница важная: в векторном PDF хранятся настоящие линии
стен и подписи размеров — их можно прочитать точно. В фотографии есть
только пиксели, и размеры придётся подтверждать вручную.

Программа развивается этапами. После каждого этапа её можно запустить
и посмотреть, что получилось.

## Шаг 1. Установите Python

Нужен **Python 3.10 или новее**. Больше ничего устанавливать не надо —
всё остальное программа поставит себе сама при первом запуске.

Проверить, есть ли он уже:

**Windows** — нажмите `Win + R`, введите `cmd`, нажмите Enter, напишите:

```
py --version
```

**Mac** — откройте программу «Терминал» и напишите:

```
python3 --version
```

Если в ответ появилось что-то вроде `Python 3.11.5` — всё в порядке,
переходите к шагу 2.

Если написано, что команда не найдена:

```
Шаг 1. Откройте сайт python.org
Шаг 2. Перейдите в раздел Downloads
Шаг 3. Скачайте версию для вашей системы и запустите установщик
Шаг 4. ВАЖНО, только для Windows: на первом экране установщика
        поставьте галочку «Add Python to PATH»
Шаг 5. Нажмите Install и дождитесь конца установки
```

## Шаг 2. Запустите программу

Самый простой способ — **двойной клик**:

| Ваша система | Какой файл открыть |
|---|---|
| Windows | `START-Windows.bat` |
| Mac | `START-Mac.command` |

Откроется чёрное окно с текстом — это нормально, так и должно быть.
**Не закрывайте его**, пока пользуетесь программой: именно оно и есть программа.

Первый запуск занимает примерно минуту: программа создаёт себе рабочее
окружение и скачивает нужные библиотеки. Следующие запуски — несколько секунд.

Когда всё будет готово, браузер откроется сам. Если не открылся —
перейдите по адресу:

```
http://localhost:8000
```

Чтобы остановить программу — просто закройте чёрное окно.

> **На Mac файл не открывается двойным кликом?**
> Откройте Терминал, напишите `chmod +x `, затем перетащите в окно Терминала
> файл `START-Mac.command` и нажмите Enter. Это нужно сделать один раз.

## Шаг 3. Ключи доступа

Без ключей программа работает: можно создавать проекты, строить 3D-модель
и ходить по квартире. Ключи нужны только для двух вещей — **прочитать
чертёж** и **создать картинку**.

### Куда вписывать

Рядом с программой лежит файл **`.env`** — он создаётся автоматически при
первом запуске. Откройте его Блокнотом (Windows) или TextEdit (Mac)
и впишите ключи после знака `=`.

```
PLAN_API_KEY=сюда ключ для чтения чертежа
IMAGE_API_KEY=сюда ключ для создания картинок
```

Сохраните файл и перезапустите программу.

### Где взять ключи

Если вы платите **рублями с обычной карты**, подойдёт российский посредник —
например **AITunnel**. Вы пополняете счёт в рублях, а он держит доступ
к зарубежным сервисам. Один аккаунт, один кошелёк, один ключ — и на чтение
чертежа, и на картинки.

```
Шаг 1. Зарегистрируйтесь на aitunnel.ru
Шаг 2. Пополните баланс — для начала хватит 400–500 рублей
Шаг 3. В личном кабинете, раздел «Ключи», создайте ключ и скопируйте его
Шаг 4. Впишите этот ключ в файл .env в ОБЕ строки:
        PLAN_API_KEY=   и   IMAGE_API_KEY=
Шаг 5. Сохраните файл и перезапустите программу
Шаг 6. Откройте «Настройки» и нажмите «Проверить доступ»
```

Адреса сервиса в файле `.env` уже вписаны — менять их не нужно.

**Названия моделей подбирать вручную не надо.** Откройте «Настройки»:
программа сама спросит у сервиса список моделей и подставит его в выпадающие
поля. Выберите там модель для чтения чертежа (подойдёт Claude) и модель
для картинок (подойдёт любая из линейки FLUX.2) и нажмите «Сохранить».

Для картинок важно одно: модель должна **принимать картинку на вход**.
В каталоге AITunnel у таких стоят значки «T + картинка → картинка».
Модель, которая умеет только «текст → картинка», геометрию вашей
квартиры не сохранит.

### Сколько это стоит

Платите только за сами запросы, подписки нет.

| Действие | Примерная цена |
|---|---|
| Разобрать дизайн-проект (один раз) | 40–60 ₽ |
| Одна картинка комнаты | 2,5–13 ₽ (зависит от модели) |
| Комната, 4 ракурса | 10–50 ₽ |
| Вся квартира, 7 помещений | 70–350 ₽ |

Реалистичный бюджет на всю квартиру со всеми переделками — **в пределах 500 рублей**.
Черновые варианты можно гонять самой дешёвой моделью, а финальные картинки
сделать самой качественной.

Программа считает расходы сама и показывает их на странице «Настройки».
Дневной лимит задаётся в файле `.env`, строка `DAILY_LIMIT_USD`.

## Шаг 4. Создайте первый проект

```
Шаг 1. Откройте http://localhost:8000
Шаг 2. Нажмите «Создать проект»
Шаг 3. Впишите название, например «Моя квартира»
Шаг 4. Укажите высоту потолка и общую площадь, если знаете
Шаг 5. Нажмите «Создать»
```

Площадь нужна не для красоты: программа сверит с ней свой расчёт по плану.
Не сойдётся — предупредит, а не покажет молча кривую модель.

## Где что лежит

```
kvartira/
├── START-Windows.bat     запуск на Windows
├── START-Mac.command     запуск на Mac
├── .env                  ваши ключи и настройки  ← этот файл вы правите
├── README.md             то, что вы сейчас читаете
├── data/                 ваши проекты, планы, картинки  ← это надо беречь
│   ├── app.db            база данных
│   └── projects/         загруженные файлы по проектам
├── logs/app.log          технические записи на случай поломки
├── app/                  код программы
└── web/                  внешний вид программы
```

**Резервная копия** делается просто: скопируйте папку `data` куда-нибудь ещё.
В ней лежит всё, что вы создали.

## Если что-то пошло не так

Программа старается объяснять проблемы человеческим языком. Если она пишет,
что делать, — сделайте это, обычно помогает.

| Что видите | Что делать |
|---|---|
| «Не найден Python» | Вернитесь к шагу 1, установите Python |
| «Не удалось скачать библиотеки» | Проверьте интернет; если включён VPN — выключите и попробуйте снова |
| «Программа не отвечает» | Чёрное окно закрылось. Запустите программу заново |
| Браузер не открылся сам | Откройте его вручную и перейдите на `http://localhost:8000` |
| «Порт занят» | Программа сама возьмёт следующий свободный и напишет адрес в окне |
| «Сервис не настроен» | Впишите ключ в файл `.env`, шаг 3 |
| Что-то непонятное | Откройте `logs/app.log`, скопируйте последние строки и покажите разработчику |

Полностью начать заново можно так: закройте программу, удалите папки
`data` и `.venv`, запустите снова. Внимание: вместе с `data` удалятся
все ваши проекты.

## Для разработчика

Запуск без создания окружения (библиотеки должны быть уже установлены):

```bash
python3 run.py --no-venv
```

Запуск на другом порту:

```bash
python3 run.py --port 8010
```

Тесты — только стандартная библиотека, ничего доустанавливать не нужно:

```bash
python3 -m unittest discover -s tests -t .
```

В `tests/fixtures/` лежат реальные планы квартиры, на которых проверяется
распознавание: план застройщика с размерами (`plan-zastroyshchik.pdf`)
и дизайн-проект с расстановкой мебели (`plan-dizayner.jpg`).
