# Бот «Монтаж»: уведомление монтажнику в Max

Когда менеджер переводит сделку в amoCRM на этап «Монтаж», монтажнику, который назначен ответственным в сделке, приходит сообщение в Max: заказ, дата, адрес, клиент и телефон.

Инструкция рассчитана на человека без опыта программирования. Идите по шагам и не перескакивайте.

## Что нужно заранее

- Аккаунт Max на организацию (у вас есть).
- Доступ администратора в amoCRM.
- Сервер в интернете, где бот будет работать круглосуточно (шаг 6), и домен (адрес сайта) с HTTPS. Это можно поручить программисту или администратору, объём работы небольшой.

## Шаг 1. Создать бота в Max и получить токен

1. Откройте платформу Max для партнёров (раздел для создания ботов на сайте Max) и войдите под аккаунтом организации. Организация должна быть подтверждена через Госуслуги или банковский ID.
2. Выберите «Создать бота», задайте имя (например, «Монтаж Септики») и описание.
3. Дождитесь модерации, если платформа её требует.
4. Скопируйте **токен бота**: длинная строка из букв и цифр. Это пароль бота. Никому не показывайте и не отправляйте в мессенджерах.

Актуальные условия смотрите на https://dev.max.ru/docs/chatbots/bots-create/create

## Шаг 2. Получить токен amoCRM

1. В amoCRM откройте Настройки, затем Интеграции.
2. Нажмите «Создать интеграцию» и выберите «Внешняя интеграция» (если на вкладке «Ключи и доступы» не будет кнопки «Долгосрочный токен», создайте вместо неё «Приватную интеграцию»; код в неё загружать не нужно).
3. Откройте вкладку «Ключи и доступы» и нажмите «Долгосрочный токен». Скопируйте токен.
4. Запомните поддомен: в адресе `mycompany.amocrm.ru` это слово `mycompany`.

## Шаг 3. Заполнить настройки

1. В папке бота скопируйте файл `.env.example` и назовите копию `.env`.
2. Откройте `.env` в Блокноте и впишите значения: поддомен и токен amoCRM, токен Max, придуманный длинный пароль в `WEBHOOK_SECRET`.
3. Названия полей сделки (`AMO_ADDRESS_FIELD`, `AMO_DATE_FIELD`, `AMO_COMMENT_FIELD`) должны совпадать с названиями в amoCRM. Если у вас поле называется иначе («Адрес монтажа»), впишите своё название.

## Шаг 4. Узнать номера этапа и сотрудников

Запустите `python show_ids.py`. Скрипт сам читает ваш файл `.env` (положите его в ту же папку).

Запуск на компьютере с Windows:
1. Установите Python с https://www.python.org/downloads/ (на первом экране установщика поставьте галочку «Add python.exe to PATH»).
2. Откройте папку `montage-bot`, щёлкните в адресной строке проводника, наберите `cmd` и нажмите Enter.
3. Выполните по очереди: `pip install requests`, затем `python show_ids.py`.

 Скрипт выведет номера всех этапов воронок и всех сотрудников amoCRM. Выпишите:
- номер этапа «Монтаж» (впишите в `.env` в `AMO_MONTAGE_STATUS_ID`);
- номер каждого монтажника.

## Шаг 5. Список монтажников

1. Скопируйте `employees.example.json` в `employees.json`.
2. Для каждого монтажника укажите `name`, `amo_user_id` (номер из шага 4) и `max_user_id`.
3. `max_user_id` монтажник узнаёт сам: он находит бота в Max и нажимает «Начать». Бот ответит: «Ваш ID в Max: ...». Этот номер вносится в файл. Для этого бот должен уже работать (после шага 6 и подключения адреса, шаг 7).

Файл читается заново при каждом уведомлении, перезапускать бота после правки не нужно.

## Шаг 6. Запустить бота на сервере

Подойдёт любой недорогой сервер (VPS, Ubuntu 22.04 или новее) и домен, который указывает на этот сервер. Команды выполняются на сервере по порядку.

```bash
apt update && apt install -y python3-venv git caddy
git clone <адрес этого репозитория> /opt/montage-bot-src
cp -r /opt/montage-bot-src/montage-bot /opt/montage-bot
cd /opt/montage-bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
```

Положите в `/opt/montage-bot` ваши файлы `.env` и `employees.json`. Затем:

```bash
cp montage-bot.service /etc/systemd/system/
systemctl enable --now montage-bot
```

Настройте HTTPS: впишите свой домен в `Caddyfile.example`, сохраните его как `/etc/caddy/Caddyfile` и выполните `systemctl restart caddy`.

Проверка: откройте в браузере `https://ваш-домен/health`. Должно появиться слово `ok`.

## Шаг 7. Сказать Max, куда присылать сообщения

На сервере в папке бота (с подгруженными значениями из `.env`) выполните:

```bash
venv/bin/python setup_max_webhook.py https://ваш-домен
```

В ответе должен быть успешный статус. После этого монтажники могут писать боту и получать свой ID (шаг 5).

## Шаг 8. Подключить amoCRM

1. В amoCRM откройте воронку: Сделки, затем Настроить воронку (Цифровая воронка).
2. На этапе «Монтаж» нажмите «Добавить триггер» и выберите «Вебхук».
3. Условие: «При переходе на этап».
4. Адрес: `https://ваш-домен/amo-webhook?secret=ВАШ_ПАРОЛЬ`, где пароль взят из `WEBHOOK_SECRET`.
5. Сохраните.

## Шаг 9. Проверка

1. Создайте тестовую сделку, назначьте ответственным себя (добавьте себя в `employees.json`) и заполните адрес и дату монтажа.
2. Переведите сделку на этап «Монтаж».
3. В течение нескольких секунд в Max должно прийти сообщение.

## Если что-то не работает

| Что видите | Что проверить |
|---|---|
| `/health` не открывается | Работает ли сервис (`systemctl status montage-bot`), указывает ли домен на сервер |
| Сообщение не приходит | Журнал: `journalctl -u montage-bot -n 50` |
| В журнале «монтажник не найден» | Номер сотрудника в `employees.json` не совпал с ответственным в сделке |
| Ошибка 401/403 от amoCRM | Токен amoCRM неверный или устарел |
| Ошибка 401 от Max | Токен Max неверный (писать без слова Bearer) |
| Ошибка «chat not found» или похожая | Монтажник не нажал «Начать» в боте |
| Поля «не указан» | Название поля в `.env` не совпадает с названием в amoCRM |

## Проверка кода (для разработчика)

```bash
pip install -r requirements.txt
python -m unittest test_app -v
```

Адрес API Max задаётся в `MAX_API_URL`. В открытых источниках встречаются `platform-api.max.ru` и `platform-api2.max.ru`: сверьтесь с актуальной документацией.
